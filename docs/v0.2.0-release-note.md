# v0.2.0 リリースノート

更新日: 2026-07-06

`v0.2.0` は、Babylon.js / babylon-mmd の更新、MMD 編集 UI の整理、FrameGraph ベースのエフェクト stack、キー編集の undo / redo 安定化、WebM 出力改善をまとめた大きめの更新です。

v0.1 系の小修正というより、今後の MMD 編集・出力機能を進めるための土台更新です。

## 主な追加・改善

### 1. Babylon.js 9 / babylon-mmd 1.2 系へ更新

- Babylon.js core / gui / loaders を 9.2.0 系へ更新
- babylon-mmd を 1.2 系へ更新
- Electron 40.4.1 系で現行起動を確認
- WebGPU / WGSL-first の描画経路を継続検証
- WebGPU 非対応時の WebGL2 fallback 経路を維持

### 2. FrameGraph エフェクト stack

右側の `Effect` パネルに FrameGraph ベースの post effect stack を追加しました。

- 効果を stack として追加 / 並べ替え / 個別 ON/OFF 可能
- stack 順と ON/OFF 状態を project 保存 / 読み込みで復元
- OFF にしても色や強度などの調整値を保持
- 新規環境では FrameGraph backend を既定に変更

主な対象:

- Bloom
- DoF
- Luminous
- LUT
- SSAO
- SSR
- Offset Shadow
- Offset Rim
- Vignette
- Grain
- Sharpen
- Chromatic Aberration
- Edge Blur
- Lens Distortion

`Offset Rim -> Bloom` のように順序を変えることで、リムに Bloom を乗せる表現もできます。

### 3. Luminous / Offset Shadow / Offset Rim

- Luminous を FrameGraph stack の効果として整理
- Bloom と Luminous の役割を分離
- Offset Shadow を追加
  - 深度差から影を落とす実験的な post effect
- Offset Rim を追加
  - 深度差からずらしたリムライト表現を作る実験的な post effect

Offset Shadow / Offset Rim は v0.2.0 時点では実験寄りです。背景や床の深度差にも反応する場合があります。

### 4. DoF とエフェクト UI の整理

- DoF の UI をリリース向けに簡略化
- Focus / F-Stop / Focal など分かりにくい項目を整理
- レンズサイズと焦点オフセット中心の調整に寄せた
- FrameGraph effect の追加 UI をポップアップ式に変更
- エフェクト名の多言語表示を整理

### 5. ミラー床 / 足下影 / 影品質設定

- ミラー床の設定 UI を整理
- ミラー床の四角 / 円形を選択可能にした
- ミラー床のデフォルト値を調整
- 足下影の名称と詳細 UI を整理
- 足下影サイズのスライダー反映を修正
- 影品質設定の一部上限値を調整

### 6. キーフレーム編集と undo / redo の安定化

キー編集系の release blocker を修正しました。

- project 読み込み時に command history を clear
- 別 project 読み込み後に古い undo が混ざる問題を修正
- Auto キー登録を command / history 経路へ接続
- 単一キー選択の delete / nudge を batch payload 経路へ統一
- 保存 / 再読み込み後に編集結果が巻き戻る問題を抑制
- キー編集の undo / redo と project round-trip を重点確認

### 7. WebM 出力改善

- WebM 出力に FrameGraph post stack が反映されるように修正
- WebM エンコーダ失敗時に UI が永久ロックされる問題を修正
- 直接 WebM 出力導線を整理し、必ず出力設定ダイアログを通すように変更
- 出力方式は速度優先に固定し、不要な選択 UI を非表示化
- WebM 出力開始時に、ビューポート側の物理剛体状態を exporter へ引き継ぐようにした

物理を馴染ませた状態から動画出力を始める用途で、本家 MMD に近い挙動を狙っています。

### 8. PNG 出力の修正

- 単発 PNG 出力時にビューポート下のシークバーなど UI が写り込む問題を修正
- PNG capture path を調整

PNG 連番出力は v0.2.0 では後回しです。詳細は既知の制限を参照してください。

### 9. 物理まわりの整理

- Bullet SPR / MPR / Off などの backend 表示と fallback 方針を整理
- package 版では MPR が未統合のため SPR fallback として扱う
- 停止中 / FPS 低下時の物理挙動を見直し
- 再生停止中でも物理 ON の場合に物理状態を維持しやすくした
- WebM 出力時の初期物理状態引き継ぎを追加

### 10. UI 整理

- メニューバーの未実装 / 重複導線を整理
- PNG 連番出力の直接導線を非表示化
- WebM 出力は出力設定ダイアログ経由へ統一
- 物理演算詳細ポップアップを追加
- 物理フレームレート設定と runtime 設定を物理演算詳細へ移動
- 剛体表示は外側の導線へ整理
- 未実装寄りの UI 項目を一部非表示化

### 11. 材質 / テクスチャ / WebGPU 安定化

- DDS texture の WebGPU fallback を追加
- DDS alpha fallback decoding を修正
- BMP alpha texture handling を修正
- 巨大平面 / 床 / 背景の描画欠けを調査・修正
- MMD 材質向けの WGSL shader 周辺を整理

### 12. ビルド / CI / リリース準備

- package version を `0.2.0` に更新
- macOS 配布物を Apple Silicon / arm64 向けに変更
- macOS GitHub Actions runner を `macos-15` に固定
- Windows x64 / macOS arm64 / Linux x64 の zip 配布に整理
- `typecheck:critical` を追加
  - `TS2304` / `TS2552` の未定義名参照を blocking 対象にした
- release workflow のビルド前に `lint` / `test:unit` / `typecheck:critical` を追加
- 余計な debug `console.log` / `console.table` を整理
- `electron-log` を third-party notices に追加

## 配布物

GitHub Release には次の zip を添付します。

- `MMD.modoki-windows-x64-0.2.0.zip`
- `MMD.modoki-mac-arm64-0.2.0.zip`
- `MMD.modoki-linux-x64-0.2.0.zip`

macOS 版は M1 / M2 / M3 / M4 など Apple Silicon 向けです。Intel Mac 向け zip は v0.2.0 の標準配布対象に含めていません。

## 既知の制限

- package 版では Bullet MPR は未統合です。現時点では SPR fallback 前提です。
- PNG 連番出力は v0.2.0 では後回しです。FrameGraph post stack 反映も未対応扱いです。
- FrameGraph / PostFX は v0.2.0 の主軸ですが、まだ実験寄りの部分があります。
- Offset Shadow / Offset Rim は深度ベースの post effect なので、背景、床、遠景の深度差に反応する場合があります。
- SSR / SSAO / 外部 LUT は環境や素材によって見え方・負荷差が出る可能性があります。
- macOS zip は署名 / notarize 済み配布物ではありません。初回起動時に Gatekeeper の確認が出る場合があります。
- Linux 版は環境によって `--no-sandbox` が必要になる場合があります。
- `npm.cmd run typecheck` は既存の非 critical 型エラーが残るため、まだ全体 blocking にはしていません。

Linux 起動例:

```bash
./MMD_modoki --no-sandbox
```

必要に応じて:

```bash
./MMD_modoki --no-sandbox --disable-setuid-sandbox
```
