# MMD本家 下パネル機能棚卸し 2026-05-31

## 参照資料

ローカル参照画像:

- `local-references/screenshots/mmd-menu/MMD_Model.png`
- `local-references/screenshots/mmd-menu/MMD_Camera.png`

これらは GitHub に上げない資料置き場の画像を見てまとめたメモ。
本家 MMD の下パネルは、選択対象によって常用操作を差し替える設計になっている。

MMD_modoki v0.2 の下パネル整理では、本家と同じ見た目を完全再現するより、次の方針を優先する。

- Model mode はボーン操作とモーフ操作を主役にする。
- Camera mode はカメラ操作を主役にし、照明/影/アクセサリを準主役にする。
- 情報欄、表示欄、再生欄は共通寄りの補助欄として小さめに扱う。
- 低頻度設定はメニューバーとポップアップへ逃がす。
- 下パネルは「現在値編集」「キー登録」「コピー/ペースト/補間」の近接性を重視する。

## 本家 MMD 下パネルの大枠

本家 MMD の下パネルは大きく以下のまとまりで構成されている。

| 欄 | Model選択時 | Camera選択時 | 性質 |
| --- | --- | --- | --- |
| 補間曲線操作 | あり | あり | 共通。キー編集寄り。 |
| モデル操作 | あり | あり | 対象ロード/削除/表示/IK/登録。Camera時は `カメラ・照明・アクセサリ` 対象の入口を兼ねる。 |
| ボーン操作 | あり | なし | Model mode の主役。選択、回転、移動、コピー、反転ペースト、登録、物理。 |
| 表情操作 | あり | なし | Model mode の主役。目/リップ/眉/その他の4分類。 |
| カメラ操作 | なし | あり | Camera mode の主役。初期化、パース、視野角、追従、登録。 |
| 照明操作 | なし | あり | Camera mode の常用欄。RGB と方向 XYZ、初期化、登録。 |
| セルフ影操作 | なし | あり | Camera mode の常用欄。影なし、モード、影範囲、登録。 |
| アクセサリ操作 | なし | あり | Camera mode の準主役。表示/影/加算、読込/削除、Transform、登録。 |
| 視点 | あり | あり | 共通。表示切替、追従、モデル/ボーン表示 toggle。 |
| 再生/音量 | あり | あり | 共通。再生、くり返し、範囲、音量。 |

## Model選択時の機能

### 補間曲線操作

見える項目:

- 補間曲線表示エリア
- 種類ドロップダウン
- `回転` 種別
- `自動設定`
- `コピー`
- `ペースト`
- `線形補間`

MMD_modoki 方針:

- 下パネルに残す。
- Model / Camera 共通でよい。
- 今の補間欄はまだ「対象トラックの補間情報表示」に寄っているため、本家のような補間曲線編集へ育てる余地がある。
- ただし初回は巨大な曲線エディタにせず、既存 timeline / interpolation state と接続しやすい小型 UI を維持する。

### モデル操作

見える項目:

- モデル選択ドロップダウン
- `読込`
- `削除`
- `表示`
- `セルフ影`
- `加算`
- IK 対象ドロップダウン
- `外`
- IK `ON/OFF`
- `登録`

MMD_modoki 方針:

- `読込` / `削除` は既に File / Edit / 情報欄の導線があるため、下パネル常設の主役にはしない。
- `表示`、`セルフ影`、`加算` はモデル情報/表示設定として扱う候補。
- IK ON/OFF は将来 Model mode の「モデル操作」または「ボーン操作」近くに置く候補。
- `登録` は対象の状態キー登録として重要だが、Action / Command の整理後に入れる。

### ボーン操作

見える項目:

- `選択`
- `回転`
- `移動`
- `BOX選択`
- `全て選択`
- `未登録選`
- `コピー`
- `ペースト`
- `反転ペースト`
- `登録`
- `初期化`
- `物理`

MMD_modoki 方針:

- Model mode の最重要欄。
- 現在の `bone-operation-section` はこの欄の受け皿として正しい。
- 初回は disabled placeholder でもよいが、将来的には以下の順で実装する。

優先度:

1. `選択 / 回転 / 移動` の mode 切替を実動作に接続する。
2. `登録` を現在ボーン transform の keyframe registration に接続する。
3. `コピー / ペースト / 反転ペースト` を Command 化して実装する。
4. `初期化` を selected bone reset として実装する。
5. `全て選択 / BOX選択 / 未登録選` は複数ボーン選択が成立してから実装する。
6. `物理` は物理 ON/OFF ではなく、ボーン操作と物理連動の意味を調べてから判断する。

### 表情操作

見える項目:

- `目`
- `リップ`
- `眉`
- `その他`
- 各分類の数値入力
- 各分類の `登録`
- 各分類のドロップダウン
- 各分類のスライダー
- 前後送りボタンのような小ボタン

MMD_modoki 方針:

- Model mode の最重要欄。
- 4分類の田の字配置は採用済み方向でよい。
- 現状の MMD_modoki はモーフ名の heuristic で分類しているが、将来的には PMX morph category を優先して分類したい。
- 各分類に `登録` を持たせるか、欄全体の登録にするかは Action 設計と合わせて決める。
- ドロップダウン + スライダー型にすると本家に近いが、MMD_modoki では複数スライダー一覧の方が一覧性は高い。ここは本家完全再現より作業効率を優先してよい。

### 視点

見える項目:

- `正面`
- `背面`
- `上面`
- `左面`
- `右面`
- `カメラ`
- `追従`
- `モデル`
- `ボーン`

MMD_modoki 方針:

- Model / Camera 共通でよい。
- Model mode では右端の小さめ欄でよい。
- `モデル` / `ボーン` toggle は現在の表示設定と接続する候補。
- `追従` は selected target follow の設計ができてから入れる。

## Camera選択時の機能

### モデル操作 / 対象操作

見える項目:

- `カメラ・照明・アクセサリ` ドロップダウン
- `読込`
- `削除`
- `表示`
- `セルフ影`
- `加算`
- 対象ドロップダウン
- `外`
- `ON/OFF`
- `登録`

MMD_modoki 方針:

- 本家では Camera mode 下パネルの対象切替入口になっている。
- MMD_modoki はトップバーに Model / Camera mode があるため、本家と同じ対象ドロップダウンを置く必要は薄い。
- Accessory は Camera mode の下パネルに残す候補だが、モデル読込/削除は File / menu に寄せる。
- `表示` / `影` / `加算` は accessory section に置く方が分かりやすい。

### カメラ操作

見える項目:

- `初期化`
- `パース`
- `視野角`
- 視野角数値
- `ボーン追従`
- 追従対象ドロップダウン
- 登録対象らしきドロップダウン
- `登録`

MMD_modoki 方針:

- Camera mode の最重要欄。
- 現状は `bone-section` の疑似 Camera として Pos/Rot/Dist/FoV を扱っているが、今後は `camera-section` または `camera-transform-section` として独立させる方がよい。
- 下パネル上の Camera mode では、まず以下を大きめに置く。

優先度:

1. Camera target / rotation / distance / FoV
2. `登録`
3. `初期化`
4. `パース`
5. `ボーン追従`

### 照明操作

見える項目:

- 光色 `赤/緑/青`
- 方向 `X/Y/Z`
- `初期化`
- `登録`

MMD_modoki 方針:

- Camera mode の常用欄として残す。
- 下パネルには light direction と light color を置く。
- 色温度、ambient、flat strength など詳細は照明/影品質ポップアップまたは Effect 側でよい。
- `登録` は light keyframe 対応時に追加する。

### セルフ影操作

見える項目:

- `影なし`
- `モード1`
- `モード2`
- `影範囲`
- 近/遠のスライダー表記
- `登録`

MMD_modoki 方針:

- Camera mode の常用欄として `影` section を分離したのは妥当。
- 下パネルには「影色」「Toon影響」「影描画距離/範囲」のような常用値を置く。
- Shadow bias、normal bias、IBL contact shadow など詳細はポップアップへ退避。
- `登録` は shadow/self-shadow keyframe の設計後に追加する。

### アクセサリ操作

見える項目:

- アクセサリ選択ドロップダウン
- `表示`
- `影`
- `加算`
- `読込`
- `削除`
- 親/対象らしきドロップダウン
- `X/Y/Z`
- `Rx/Ry/Rz`
- `Si`
- `Tr`
- `登録`

MMD_modoki 方針:

- Camera mode の準主役。
- `.x` アクセサリは MMD ワークフロー上重要なので下パネルに残す。
- `X/Y/Z/Rx/Ry/Rz/Si/Tr` を一覧できる compact transform UI は必要。
- `読込` / `削除` は File menu にもあってよいが、アクセサリ欄内にもあると本家に近く使いやすい。
- `登録` は accessory transform keyframe の Command 対応後に追加する。

## 共通欄

### 再生 / 音量

見える項目:

- `再生`
- `くり返し`
- 開始/終了フレーム欄
- `フレ・スタート`
- `フレ・ストップ`
- 音量スライダー

MMD_modoki 方針:

- 本家では下パネル右側の共通欄。
- MMD_modoki では現在左 timeline panel に再生欄がある。
- 将来、左 timeline をより timeline 表示に集中させるなら、再生欄を下パネル共通欄に統合する余地がある。
- ただし下パネルが既に窮屈なので、再生欄移動は今すぐではなく、section の折りたたみ/compact 化と合わせて検討する。

### 情報欄

本家の下パネルには MMD_modoki のような情報欄はない。

MMD_modoki 方針:

- 本家から少し外して、情報欄は左端に固定してよい。
- ただし重要度は編集欄より低いため、幅は小さめでよい。
- モデル名、頂点/ボーン/モーフ数、表示/削除の導線程度に絞る。

## MMD_modokiへの反映優先度

### 高

- Model mode のボーン操作欄を実動作に接続する。
- Model mode のモーフ4分類を安定化する。
- Camera mode のカメラ操作欄を疑似 bone から独立させる。
- 照明と影を Camera mode の常用欄として整理する。
- アクセサリ transform を Camera mode の準主役として扱う。

### 中

- 補間欄を本家の補間曲線操作へ近づける。
- モデル表示/セルフ影/加算/IK ON/OFF の配置を整理する。
- View 欄に `モデル` / `ボーン` toggle と `追従` を追加する。
- 再生欄を下パネルへ統合するか再検討する。

### 低 / 後続

- BOX選択。
- 未登録選。
- 反転ペースト。
- ボーン追従。
- self-shadow mode 1/2 の本家互換寄せ。
- 出力や重力など低頻度設定を下パネルへ戻すこと。

## レイアウト重み付け案

### Model mode

主役:

- ボーン操作
- ボーン位置/角度
- モーフ

補助:

- 補間
- 情報
- 表示

推奨順:

```text
情報 / 補間 / ボーン操作 / ボーン / モーフ / 表示
```

ただし、補間を左タイムライン寄りの編集操作と見るなら、以下も候補。

```text
補間 / 情報 / ボーン操作 / ボーン / モーフ / 表示
```

### Camera mode

主役:

- カメラ操作

準主役:

- 照明
- 影
- アクセサリ

補助:

- 情報
- 補間
- 表示

推奨順:

```text
情報 / 補間 / カメラ操作 / 照明 / 影 / アクセサリ / 表示
```

## 次にやるなら

1. 現在の MMD_modoki 下パネル section と、この棚卸し表を照合する。
2. `bone-operation-section` のボタンを Action に接続する優先順位を決める。
3. Camera mode の疑似 bone UI を `camera-section` として独立させる設計を切る。
4. モーフ分類を heuristic ではなく PMX morph category 優先にする。
5. 下パネルが窮屈なため、section の折りたたみ、重要欄の拡大、低重要欄の compact 化を続ける。
