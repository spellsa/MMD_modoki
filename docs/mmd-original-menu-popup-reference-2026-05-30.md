## メニューバー構成

本家 MMD のメニューバーは以下の大分類。

- ファイル
- 編集
- 表示
- 背景
- 表情
- 物理演算
- モーションキャプチャ
- ヘルプ

MMD_modoki でもこの大分類を基本としてよい。ただし、モーションキャプチャは現時点では実装予定が薄いため、v0.2.0 では非表示または将来復活候補とする。

## ファイル

本家の主な項目:

- 新規
- 開く
- 上書き保存
- 名前を付けて保存
- AVIファイルに出力
- 画像ファイルに出力
- ポーズデータ読込 / 保存
- モーションデータ読込 / 保存
- WAVファイル読込
- WAV再生設定
- デフォルトフォルダを前回位置とする
- 終了

MMD_modoki 側の対応:

- project 保存 / 読込は `ファイル` 配下でよい。
- PMX / VMD / 音源 / 背景画像動画の読込導線は、現状の `ファイル読込...` と個別読込の併用でよい。
- 出力系は `ファイル` 配下に置く。WebM / PNG / PNG連番は本家の AVI / 画像出力に相当する。
- WebM 出力設定ポップアップは、本家の `AVI出力設定` に近い位置づけ。
- 出力画面サイズは、本家では動画出力とは別の小型ポップアップとして存在する。MMD_modoki でも将来 `出力サイズ設定...` を分離する候補。

## 編集

本家の主な項目:

- ボーン / カメラ数値入力
- ボーン / カメラ角度初期化
- 不要フレーム削除
- カメラ / 照明 / セルフ影 / 重力 / アクセサリフレーム全選択
- カメラフレーム位置角度補正
- ボーン / 表情 / 表示 IK 外親フレーム全選択
- 別フレームへペースト
- 空フレーム挿入 / 列フレーム削除
- ボーンフレーム位置角度補正
- 表情大きさ補正
- センター位置バイアス付加

MMD_modoki 側の対応:

- 編集メニューは Action / Command と相性がよい。Undo / Redo、キーフレーム登録、削除、移動、補間操作の住所にする。
- `位置角度補正` 系は小型ユーティリティポップアップとして後続候補。
- `全選択` や `空フレーム挿入` / `列フレーム削除` は、タイムライン編集機能が成熟してから追加する。
- 現時点ではモデル / カメラ / ボーン / モーフのモード別 UI 整理を優先し、本家項目を一気に増やさない。

## 表示

本家の主な項目:

- 出力サイズ
- 別窓
- モデル編集中カメラ・照明追従
- 情報表示
- 座標軸表示
- 地面影表示
- 地面影色設定
- 地面影色透明化
- 半透明化
- モデル非表示
- エッジ太さ
- エッジ色
- アンチエイリアス
- ミップマップ
- セルフシャドウ表示
- ワイヤーフレーム表示
- フルスクリーン表示
- fps制限
- 省エネモード

MMD_modoki 側の対応:

- 表示 toggle は `表示` メニューへ寄せる方針でよい。
- エッジ設定ポップアップは本家の `エッジ太さ` / `エッジ色` に対応する入口として育てる。
- 現時点の MMD_modoki はエッジ幅のみ。エッジ色は将来の追加候補。
- 照明/影品質設定ポップアップは、セルフシャドウ表示や影品質に近い低頻度設定の置き場として妥当。
- fps制限、アンチエイリアス、省エネ系は `表示` 配下に集約しやすい。

## 背景

本家の主な項目:

- アクセサリ編集
- モデル描画順
- モデル計算順
- 背景黒化
- 背景AVIファイル読込
- 背景画像ファイル読込
- 背景AVI表示
- 背景画像表示
- スクリーン用キャプチャ設定

MMD_modoki 側の対応:

- 背景画像 / 動画の読込、表示切替、黒背景は `背景` メニューおよび背景設定ポップアップで扱う。
- Mirror床は本家そのものの背景項目ではないが、MMD_modoki では背景/床系の低頻度設定として背景設定ポップアップに入れてよい。
- `モデル描画順` / `モデル計算順` は本家では背景メニュー配下。MMD_modoki でも将来、モデル/アクセサリ順序管理の小型ポップアップとして候補にする。

## 表情

本家は表情編集と表情フレーム操作の入口を持つ。

MMD_modoki 側の対応:

- モーフ UI はモデルモード専用の下パネル項目として残す。
- メニュー側には `現在フレームに登録` や `モーフを登録` などの補助導線を置く。
- `表情大きさ補正` は後続の小型ポップアップ候補。

## 物理演算

本家の主な項目:

- オン/オフモード
- 常に演算
- トレースモード
- 演算しない
- 再生時は常にオン/オフモードにする
- 剛体表示
- 重力設定
- 剛体位置初期化
- 床
- 物理影響ボーン選択
- 物理ON/OFFフレーム変換
- 物理エンジンについて

MMD_modoki 側の対応:

- 物理 ON/OFF、剛体表示、重力設定は `物理演算` 配下でよい。
- 重力設定ポップアップは本家より少し統合寄りで、物理 ON/OFF や剛体表示も入っている。v0.2.0 の整理としては許容。
- 本家寄せを強めるなら、将来 `重力設定` は加速度/方向だけにし、物理 ON/OFF と剛体表示はメニュー toggle に戻す。
- `床` は本家では物理演算メニューにもあるため、MMD_modoki でも `表示` と `物理演算` のどちらからも到達できる候補。

## ヘルプ

本家はバージョン情報などの小型ダイアログを持つ。

MMD_modoki 側の対応:

- About / Shortcuts / Log folder は `ヘルプ` 配下でよい。
- runtime 切替や language は現状 Help に残っているが、将来的には Preferences または toolbar の専用領域へ移す余地がある。

## ポップアップの傾向

本家 MMD のポップアップは全体的に以下の特徴がある。

- 小さい。
- 1目的1ダイアログ。
- 入力項目は少ない。
- OK / キャンセル、または 登録 / 閉じる のような明確な終端を持つ。
- 複雑な常設パネルではなく、低頻度の補正や設定を一時的に開く。
- リスト + 上下ボタンのような単純な操作で順序管理する。

MMD_modoki のポップアップ設計でもこの方向を基本にする。

## 下パネル切替の観察

`MMD_Model.png` はモデル編集時の下パネル構成を見る資料。
ボーン操作、モデル操作、補間曲線操作、視点、再生などが中心になる。

`MMD_Camera.png` はカメラ/照明/アクセサリ編集時の下パネル構成を見る資料。
カメラ操作、照明操作、セルフ影操作、アクセサリ操作、視点、再生などが中心になる。

この差分は、MMD_modoki の `モデルモード` / `カメラモード` で下パネル構成を変える方針の根拠になる。
タイムラインは共通でよいが、下パネルは対象に応じて常用項目を切り替える方が本家 MMD に近い。
低頻度設定はメニューバーとポップアップへ逃がし、下パネルはキーフレーム登録や頻出操作を優先する。

## 個別ポップアップ観察

### 動画出力

本家は `AVI出力設定` として、録画サイズ、フレームレート、録画フレーム、WAVE出力、3D出力、ビデオ圧縮コーデックを持つ。

MMD_modoki の WebM 出力設定は、サイズ、FPS、フレーム範囲、音声、capture mode を持つため、おおむね対応している。

### 出力画面サイズ

幅と高さだけの小型ダイアログ。

MMD_modoki では現状 WebM 出力設定にサイズを含めているが、将来は `出力画面サイズ設定...` を別ポップアップにしてもよい。

### 重力設定

本家は加速度、向き X/Y/Z、ノイズ付加、登録、閉じる。

MMD_modoki は加速度、方向 X/Y/Z、物理演算、剛体表示、simulation rate を含めている。
本家より広めだが、物理詳細設定の初回実装としては扱いやすい。

### エッジ色

本家は OS 標準に近い色選択ダイアログ。

MMD_modoki ではまずエッジ幅を実装済み。エッジ色を追加する場合は、独自大型UIより小型の色入力を優先する。

### モデル描画順 / モデル計算順

本家はリスト、上/下、OK、キャンセル。

MMD_modoki でモデルやアクセサリの描画順/計算順を扱う場合、この形を踏襲できる。

### 位置角度補正

本家は倍率と加算値を X/Y/Z で指定する小型ユーティリティ。

MMD_modoki では Command 化しやすい編集機能。実装するなら Undo/Redo 対象にする。

### 表情大きさ補正

本家は表情値に対する小型補正ダイアログ。

MMD_modoki ではモーフ編集の後続候補。

## MMD_modoki への反映方針

- 本家と同じ大分類のメニューバーを維持する。
- メニュー項目は一気に増やさず、実装済み機能と近いものから追加する。
- 常用操作は下パネルや toolbar に残し、低頻度設定や補正をポップアップへ移す。
- 下パネルはモデル欄 / カメラ欄のような対象選択に応じて構成を変える。
- ポップアップは小さく、1目的1画面を基本にする。
- 本家にあるが MMD_modoki で未実装の機能は、disabled placeholder よりも未表示を基本にする。
- 将来追加する場合は、Action / Command 経路を先に決める。

## 次の候補

- `出力画面サイズ設定...` を WebM 出力設定から独立させるか検討する。
- `エッジ色` をエッジ設定ポップアップへ追加するか検討する。
- `モデル描画順` / `モデル計算順` ポップアップをモデル/アクセサリ管理の候補にする。
- `ボーン位置角度補正` / `カメラ位置角度補正` は Command 対応後の編集系ユーティリティとして検討する。
- `重力設定` から物理 ON/OFF / 剛体表示を分離し、本家に近い小型ダイアログへ寄せるか検討する。

## 2026-05-30 MMD_modoki メニュー整理結果

v0.2.0 の初回メニューバー整理として、実装済み機能の住所を本家 MMD の大分類に寄せた。

- `表示` は表示 toggle と視点切替に絞り、剛体表示を外した。
- `選択モデルを削除` は表示操作ではなく編集操作として、`編集` メニューへ移した。
- `背景` は背景画像/動画、黒背景、Mirror床、背景設定への入口に絞り、Mirror解像度の直メニューは背景設定ポップアップへ集約した。
- `物理演算` は物理 ON/OFF、剛体表示、重力設定の入口に整理した。
- 言語選択はトップバー常時表示を正とし、`ヘルプ` メニューからは外した。

未実装機能は disabled placeholder を置かず、必要になった段階でメニューへ追加する方針を継続する。
