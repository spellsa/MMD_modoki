# v0.2 UI レイアウト構成図メモ 2026-05-30

## 領域の責務

### Menu Bar

本家 MMD のメニュー構成を基本にする。

```text
ファイル
編集
表示
背景
表情
物理演算
モーションキャプチャ
ヘルプ
```

MMD_modoki 独自機能の受け皿として `効果 / Effect` を追加するかは未決。

メニューバーの役割:

- 低頻度操作の住所。
- 詳細 popup / dialog / drawer の入口。
- 常設 toolbar の過密を避ける。
- 既存 i18n 方式で翻訳する。
- ActionDispatcher へ接続する。

### Top Status / Compact Toolbar

常に見えてほしい状態と頻出操作だけを置く。

候補:

- Model / Camera mode switch
- Undo / Redo
- active target
- engine / backend status
- physics status
- export busy / background task status
- toast / status text

ここに大量の表示 toggle や出力設定を置かない。

### Left Timeline

Model Mode / Camera Mode 共通。

置くもの:

- frame ruler
- waveform
- timeline tracks
- keyframe dots
- selected frame
- Start / Stop / range marker
- marker / snap / selection は後続候補

置かないもの:

- 詳細な値編集
- 出力 codec / quality
- PostFX 詳細
- 低頻度の表示 toggle

Timeline は mode で分けない。モデルキーとカメラキーは同じ時間軸で確認する。

### Viewport

canvas は共通だが、interaction behavior は mode で変える。

```text
Model Mode
  Viewport = View Camera
  orbit / pan / zoom は作業用視点
  camera keyframe には影響しない
  bone pick / gizmo 操作を重視

Camera Mode
  Viewport = MMD Camera
  orbit / pan / zoom は MMD camera current value に反映
  camera keyframe dirty を立てる
  DoF / PostFX / output aspect preview を重視
```

用語:

```text
View Camera
  作業用視点。カメラキーには影響しない。

MMD Camera
  モーション上のカメラ。カメラキー / 補間 / 出力に影響する。
```

### Effect Panel

現行の「model target なら shader、Camera target なら PostFX」という対象選択連動を弱める。

カテゴリ案:

```text
Shader / Material
  model material
  accessory material
  MMD shader preset
  model edge settings
  external / bundled WGSL route

Post Effect
  color correction
  LUT
  bloom / tone mapping
  DoF
  lens
  fog

Experimental
  SSR
  motion blur
  volumetric light
  hidden / diagnostics controls

FrameGraph Diagnostics
  stack / blocks
  shared buffers
  logical RT count
```

mode による優先表示:

```text
Model Mode
  Shader / Material を優先表示

Camera Mode
  Post Effect を優先表示
```

ただし、片方を完全に消しすぎず、tab / accordion / section で到達できるようにする。

### Bottom Panel

下パネルは、共通欄と mode 別欄に分ける。

共通欄:

```text
情報
アクセサリ
再生
```

Model Mode 欄:

```text
ボーン
モーフ
補間
モデルキー
```

Camera Mode 欄:

```text
カメラ
照明
影
DoF
カメラキー
```

再生欄は現行の timeline 上部から下パネルへ統合する候補。左パネルは timeline 表示に集中させる。

## Model Mode 構成

```text
+--------------------------------------------------------------------------------+
| Menu Bar                                                                       |
+--------------------------------------------------------------------------------+
| Mode: [Model]  Undo Redo  Target: Model / Bone / Morph  Engine Status          |
+----------------------+------------------------------------+--------------------+
| Timeline             | Viewport                           | Effect Panel       |
| common timeline      | View Camera                        | Shader / Material  |
| model tracks focus   | free orbit / pan / zoom            | Accessory shader   |
| camera tracks visible| bone pick / gizmo                  | Model edge         |
+----------------------+------------------------------------+--------------------+
| Bottom Common: 情報 | アクセサリ | 再生                                      |
| Bottom Model:  ボーン | モーフ | 補間 | モデルキー                              |
+--------------------------------------------------------------------------------+
```

Model Mode の主役:

- bone transform
- morph weight
- model keyframe
- interpolation
- material / shader
- accessory selection / transform

Model Mode の viewport:

- 作業用 View Camera。
- camera keyframe には影響しない。
- モデルを見やすい角度へ自由に回せる。

## Camera Mode 構成

```text
+--------------------------------------------------------------------------------+
| Menu Bar                                                                       |
+--------------------------------------------------------------------------------+
| Mode: [Camera]  Undo Redo  Target: Camera  Engine Status  Output Aspect         |
+----------------------+------------------------------------+--------------------+
| Timeline             | Viewport                           | Effect Panel       |
| common timeline      | MMD Camera                         | Post Effect        |
| camera tracks focus  | camera current value editing       | DoF / LUT / Bloom  |
| model tracks visible | output aspect preview              | FrameGraph diag    |
+----------------------+------------------------------------+--------------------+
| Bottom Common: 情報 | アクセサリ | 再生                                      |
| Bottom Camera: カメラ | 照明 | 影 | DoF | カメラキー                             |
+--------------------------------------------------------------------------------+
```

Camera Mode の主役:

- MMD camera current value
- camera keyframe
- camera interpolation
- light
- shadow
- DoF
- PostFX
- output look preview

Camera Mode の viewport:

- MMD Camera 編集対象。
- orbit / pan / zoom は camera current value に反映する。
- camera keyframe dirty を立てる。

## Menu から開く詳細 UI

メニューバーは入口。詳細設定や状態表示は popup / dialog / drawer で開く。

```text
Menu Bar
  -> Dropdown menu
  -> Popup panel
  -> Modal dialog
  -> Drawer
```

候補:

```text
ファイル
  Export Settings dialog / drawer
  Project Info dialog

編集
  Preferences dialog

表示
  View options popover

背景
  Background Settings dialog
  Skydome Settings dialog
  Mirroring Floor Settings dialog

物理演算
  Physics Settings popover / dialog
  Gravity Settings popover

ヘルプ
  About dialog
  Keyboard Shortcuts dialog
  Diagnostics drawer
```

表示形式の使い分け:

```text
Dropdown menu
  command list

Popover panel
  軽い設定

Modal dialog
  長い設定 / 確定操作

Drawer
  diagnostics / inspector
```

## Export Settings の位置づけ

現行の出力欄は、常設 UI から縮小する。

常設に残す候補:

- Start / Stop
- 再生範囲の見え方
- current frame
- export busy status

Export Settings dialog / drawer へ移す候補:

- PNG / PNG sequence / WebM
- resolution / aspect
- FPS
- quality
- codec
- audio include
- output path
- export execution

## Background Settings の位置づけ

背景画像 / 動画は、読み込み入口だけでなく管理 UI が必要。

Background Settings 候補:

- enabled
- source type: none / image / video / color / skydome
- current file path
- choose image
- choose video
- clear
- fit mode
- opacity
- loop video
- mute video

背景は mode 専用ではなく、Scene / Background の共通設定として扱う。

## Model Edge の位置づけ

Model Edge は常設スライダーから外し、menu + popup / dialog に寄せる候補。

入口候補:

```text
表示
  Toggle Edge

効果 / Shader Material
  Model Edge Settings...
```

Model Edge Settings 候補:

- enabled
- width
- color later
- per-model override later
- per-material override later
- reset

ON / OFF は表示系、幅や見た目は shader / material / rendering style に近い。

## FrameGraph / Custom Effect の位置づけ

v0.2.0 の本筋では、FrameGraph custom effect は実装しない。

ただし UI には将来の受け皿を残す。

```text
Effect Panel
  FrameGraph Diagnostics
    Shared Buffers
    Stack / Blocks
    RT count

Later
  Custom Post Effect Stack
  Shader Layer / RT Layer
```

custom post effect は将来、Babylon.js 公式 Node Render Graph / FrameGraph に寄せつつ、MMD_modoki UI では直列 stack subset として扱う候補。
